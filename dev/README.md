# Local dev stack

NATS 2.15.3 (JetStream) and Postgres 17 for local development and the integration tests of
`go-common` (`bus`, `outbox`, `inbox`). Dev only; no staging or production config lives here yet.

    dev/up.sh            # generates .nats/accounts.conf + seeds, then docker compose up
    docker compose -f dev/compose.yaml down -v

`accounts.conf` is generated by `go run ./cmd/busdev` in go-common from the event schemas
(`x-publisher`, `x-subscribers`): one nkey user per service plus an admin user used only by
provisioning. Seeds are written to `.nats/seeds/` (gitignored, dev-only). Streams and consumers are
created by `bus.Provision` with the admin credential; services never hold it (ADR-0011 B8).

Ports: NATS `HOSTRY_NATS_PORT` (4222), Postgres `HOSTRY_PG_PORT` (5432), both bound to 127.0.0.1.
